# Карта континента Corentis — Lands of Lords

Живая карта разведанного континента **Corentis** в браузерной игре
[Lands of Lords](https://www.landsoflords.com) — что где находится (месторождения,
типы местности), кому принадлежит, плюс топ владельцев самых ценных
месторождений.

**Открыть карту:** https://lol-continent-map.rammthaok.workers.dev/
(зеркало: https://tverzar.github.io/landsoflords-map/)

Данные собираются вручную обходом клеток континента через игровой API — это
долго (сотни тысяч клеток), поэтому карта никогда не будет полностью
разведана одним человеком. Чем больше игроков помогает — тем полнее и
свежее карта.

## Как помочь разведать карту

1. Скачайте `LOL-MapHelper.exe` с [последнего релиза](../../releases/latest)
   — двойной клик, ничего устанавливать не нужно (Python не требуется).
2. Вкладка **«Локально»** → войдите под своим игровым аккаунтом.
3. Отметьте галочку **«Делиться прогрессом с проектом»**.
4. Нажмите **«Запустить»**.

Дальше всё автоматически: инструмент сам сканирует континент волной от
вашего домена, пропускает уже известные клетки (сначала скачивает список
того, что уже разведано — чтобы не гонять повторные запросы по чужой
работе) и периодически присылает найденное на сервер проекта небольшими
порциями, пока вы играете.

**Что уходит с вашего компьютера:** только результаты сканирования клеток
(тип местности, качество, занята/свободна, кем занята — то же самое, что
и так видно любому в самой игре). Игровой логин/пароль никогда никуда не
уходят, кроме официального сервера игры — тот же вход, каким вы обычно
пользуетесь. Присылки не попадают на карту автоматически — они сначала
проверяются вручную, прежде чем объединиться с основными данными.

## Исходный код

В папке [`helper-tool/`](helper-tool/) — полный исходный код инструмента
`LOL-MapHelper.exe`, из которого он собирается (PyInstaller, `--onefile
--windowed map_app.py`). Публикуется для прозрачности — чтобы можно было
убедиться, что делает программа, прежде чем вводить туда игровой пароль.

Зависимости — `pip install -r helper-tool/requirements.txt`, затем
`python helper-tool/map_app.py`.

Серверная часть проекта (сам постоянный скан, сборка карты, приём и
проверка присылок) в этом репозитории не публикуется — здесь только то,
что нужно для доверия к клиентскому инструменту и для хостинга готовой
карты через GitHub Pages.
