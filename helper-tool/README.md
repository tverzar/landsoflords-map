# Помощник разведки карты

Десктоп-приложение (Windows), которое сканирует карту вашего континента
и присылает найденное в общий проект — то же самое, чем строится
[живая карта](https://tverzar.github.io/landsoflords-map/) в этом
репозитории.

**Скачать:** [`LOL-MapHelper.exe`](LOL-MapHelper.exe)

Публикуются также полные исходники (`map_app.py` + прямые зависимости:
`fast_map.py`, `lol_api.py`, `continent_scan_cli.py`, `profiles.py`,
`remote.py`, `styles.py`), чтобы можно было убедиться, что делает
программа, прежде чем вводить туда игровой пароль. Пароль хранится
только в системном хранилище учётных данных Windows (модуль `keyring`),
никогда не сохраняется в коде или в открытом виде на диске.

Серверная часть проекта (сам непрерывный скан, сборка карты, приём и
проверка присылок) остаётся в приватном репозитории.

## Сборка из исходников

```
pip install -r requirements.txt pyinstaller
pyinstaller LOL-MapHelper.spec --clean
```
